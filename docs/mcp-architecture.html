Architecture

What it does

The server loads graph.json into NetworkX at startup and exposes graph operations as MCP tools. Every node carries its source file and line (kiotel_hardware/kiosk_Source/kiosk/frmMainScreen.cs L464), so answers are citations, not vibes. Every edge carries provenance: EXTRACTED = structural fact (import, call, FK, doc reference), INFERRED = curated inference (includes the cross-repo concept→code bridges), AMBIGUOUS = flagged uncertainty kept visible on purpose.

How a query flows

  1. Agent calls tools/call → query_graph with a natural-language question over JSON-RPC at /mcp.
  2. The server fuzzy-matches question terms against node labels to pick seed nodes.
  3. BFS traversal (depth 3 by default) expands the seeds across EXTRACTED and INFERRED edges — including the cross-repo bridges.
  4. Results are trimmed to a ~2,000-token budget (the response says TRUNCATED: showing N of M when it cuts).
  5. Each returned node includes src=…file L… and its community id — follow up with get_community / get_neighbors to drill in.
